# kube-sre-mcp v0.1.0

First public release of kube-sre-mcp.

## Highlights

* stdio MCP server
* kubeconfig-only Kubernetes authentication
* Kubernetes troubleshooting and SRE diagnostics
* Events and log analysis
* CrashLoopBackOff / OOMKilled / image-pull / scheduling diagnostics
* resource relationship graph
* ranked diagnostic hypotheses
* actionable recommendations
* read-only by default
* optional guarded actions

## Supported platforms

* Linux amd64
* Linux arm64
* macOS amd64
* macOS arm64
* Windows amd64

## Current limitations

* stdio only
* kubeconfig only
* no in-cluster authentication
* no deterministic causal RCA
